# English Room

말로 대화하며 영어를 배우는 나만의 교실. 58세 영어 선생님 Mr. Bennett가 대화를 이끌고, 대화를 마칠 때마다 내 영어 실력과 이야기를 기록해 다음 대화로 이어 갑니다. 선생님과 함께 새로운 대화 상대(친구, 회사 동료 등)를 만들 수도 있어요.

- **두뇌:** Google Gemini API (내 API 키, 무료 등급으로 시작 가능)
- **음성:** 브라우저 기본 음성 인식 + 음성 합성 (무료)
- **기록:** 이 기기의 브라우저(localStorage)에만 저장. ☰ 메뉴에서 백업 파일로 저장/불러오기
- 서버 없음. 정적 파일만으로 GitHub Pages에서 동작

## 쓰는 법
1. 사이트를 열고 [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 만든 Gemini API 키를 붙여 넣기
2. 휴대폰 브라우저 메뉴에서 "홈 화면에 추가"
3. Mr. Bennett를 눌러 첫 수업 시작, 🎤를 눌러 말하기

API 키는 저장소에 들어가지 않고 각자의 브라우저에만 저장됩니다. Google Cloud 콘솔에서 키의 "웹사이트 제한"을 이 사이트 주소로 걸어 두면 더 안전합니다.
